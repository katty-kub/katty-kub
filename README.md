## 📌 Vybrané projekty

### [Manual Testing Portfolio](https://github.com/katty-kub/manual-testing-portfolio)

QA portfolio, ve kterém postupně dokumentuji celý proces manuálního testování jednoduché webové aplikace s přihlašovacím formulářem a uživatelským dashboardem.

Projekt zahrnuje:

- požadavky aplikace a test plan,
- testovací scénáře a test cases,
- pozitivní a negativní testování,
- Equivalence Partitioning a Boundary Value Analysis,
- smoke a regression checklisty,
- bug reporty včetně severity a priority,
- exploratory testing,
- závěrečný test report.

**Zaměření:** Manual Testing · Test Cases · Bug Reporting · Smoke Testing · Regression Testing · Exploratory Testing

> Projekt je ve vývoji a jednotlivé části průběžně doplňuji.

### [CLI Poznámkovník](https://github.com/katty-kub/CLI-poznamkovnik)

Aplikace propojující příkazovou řádku, REST API, Express a PostgreSQL. Umožňuje vytvářet, zobrazovat, upravovat, mazat, vyhledávat a filtrovat poznámky.

Z pohledu testování jsem si na projektu procvičila:

- kontrolu API endpointů a stavových kódů,
- validaci vstupů a chybové scénáře,
- testování CRUD operací,
- integrační testy pomocí Node Test Runneru a Supertestu,
- práci s očekávanými a neočekávanými vstupy.

**Technologie:** JavaScript · Node.js · Express · PostgreSQL · REST API · Supertest

### [Nákupní seznam](https://github.com/katty-kub/shopping-list)

Webová aplikace vytvořená v Reactu a TypeScriptu. Uživatel může přidávat položky, vybírat jejich kategorii, označovat je jako koupené a odstraňovat je ze seznamu.

Z pohledu testování jsem si na projektu procvičila:

- testování uživatelských scénářů,
- kontrolu formulářů a vstupních hodnot,
- ověřování změn stavu aplikace,
- testování komponent pomocí Vitestu a React Testing Library,
- hledání okrajových situací v uživatelském rozhraní.

**Technologie:** React · TypeScript · JavaScript · Vitest · React Testing Library
